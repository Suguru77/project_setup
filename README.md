## Pre‑commit hook
Place `pre_commit.ps1` in the repository root and configure your VCS (or snapshot‑guard workflow) to execute it before any commit:
```powershell

```
The hook simply runs `ci\check_redteam.ps1` and aborts on failure.

## `process_guard.js`
The JavaScript wrapper provides two helper functions:
- `registerProcess(pid)` – records a PID in `process_guard_state.json`.
- `cleanup()` – kills all recorded PIDs and clears the state file.
It is useful for Node‑based tooling that needs deterministic cleanup.

## Creating a remote GitHub repository
`create_github_repo.ps1`:
1. Requires the environment variable `GITHUB_TOKEN` (a personal access token with `repo` scope).
2. Calls the GitHub REST API to create a repository named `project_setup` under the authenticated user.
3. Uploads every file in the local directory via the *Create or update file* endpoint.
4. Prints the repo URL; GitHub Actions will automatically run the CI workflow defined in `.github/workflows/ci.yml` (if added later).
